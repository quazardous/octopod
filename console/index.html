Add a project
  1. In the project's folder, an octopod.yaml: what to expose of its compose file, or recipes instead of one. 
    expose:
  - service: web        # http://<project>.localhost
    services:
  app: { recipe: node-app }
  db:  { recipe: postgres }
  2. There: octopod up — it registers the project the first time, and starts it.
  3. It shows here, served at http://<project>.localhost. octopod recipes lists the recipes; octopod plan shows what up would run.
